# Ajustes

Todo lo que se configura de LordOS está en Ajustes. El campo de arriba busca entre las secciones.

| Sección | Qué tiene |
|---|---|
| [General](settings:general) | Este equipo: nombre, software y almacenamiento |
| [Apariencia](settings:appearance) | Estilo de escritorio (Lord Flow o Lord Classic), modo oscuro o claro, color de acento, transparencias |
| [Fondo de pantalla](settings:wallpaper) | El fondo del escritorio |
| [Pantallas](settings:displays) | Resolución, escala, disposición de varias pantallas, Luz nocturna |
| [Red](settings:network) | Cable, Wi-Fi y VPN (ver [Red](help:network)) |
| [Sonido](settings:sound) | Salidas, entradas, volumen por app (ver [Sonido](help:sound)) |
| [Impresoras y escáneres](settings:printers) | Ver [Imprimir](help:printing) |
| [Portapapeles](settings:clipboard) | Historial y privacidad (ver [Portapapeles](help:clipboard)) |
| [Compartir](settings:sharing) | Escritorio remoto (ver [Escritorio remoto](help:remote-desktop)) |
| [Idioma y región](settings:language) | Idioma, formatos, zona horaria (ver [Idioma y región](help:language)) |
| [Teclado](settings:keyboard) | Distribuciones y métodos de entrada (ver [Teclado](help:keyboard)) |
| [Trackpad](settings:trackpad) | Si hay touchpad (ver [Touchpad](help:trackpad)) |
| [Privacidad](settings:privacy) | Permisos de las apps (ver [Privacidad](help:privacy)) |
| [Usuarios](settings:users) | Cuentas e inicio automático (ver [Usuarios y sesiones](help:users)) |
| [Actualizaciones](settings:updates) | Paquetes de Debian (ver [Actualizaciones](help:updates)) |
| [Sesión](settings:session) | Cerrar la sesión |

Los cambios se guardan solos. Lo que afecta a todo el equipo (red, usuarios, zona horaria,
paquetes) pide ser administrador.

## Varias pantallas

En [Pantallas](settings:displays), con más de una pantalla conectada, cada pantalla de la
disposición muestra su número: la principal (la que tiene la barra de menú y el Dock) es la 1.

- **Identificar:** hacé clic en una pantalla de la disposición, o en el botón **Identificar**, y su
  número aparece grande en la pantalla real por un momento, para saber qué monitor es el 1 y cuál el 2.
- **Ordenar:** arrastrá las pantallas para que coincidan con cómo están en tu escritorio. Se pegan
  borde con borde y alinean sus bordes superiores, inferiores, laterales o sus centros cuando están
  cerca. Al soltarla, una pantalla siempre toca a otra y nunca se superpone; si la soltás en un
  espacio vacío, se mueve al borde más cercano.

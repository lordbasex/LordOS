# Áreas de trabalho

Separe trabalhos diferentes em áreas de trabalho: cada uma tem suas janelas, e todas as telas trocam juntas.
Você pode ter até nove.

## A visão geral

A visão geral mostra as janelas desta área de trabalho e, em cima, todas as áreas de trabalho.

- **Lord Flow:** ⌃↑, ou Visão geral no menu Janela.
- **Lord Classic:** ❖Tab, ou o botão ao lado da busca.

Clique em uma janela para ir até ela e em uma área de trabalho para vê-la. O **+** adiciona uma, e o × de uma área
de trabalho a fecha: as janelas passam para a seguinte. Arraste uma janela para uma área de trabalho para movê-la.

## Trocar de área de trabalho

| | Lord Flow | Lord Classic |
|---|---|---|
| Anterior ou seguinte | ⌃← ⌃→ · ❖⌃← ❖⌃→ | ❖⌃← ❖⌃→ |
| Nova área de trabalho | Na visão geral | ❖⌃D |
| Fechar esta área de trabalho | Na visão geral | ❖⌃F4 |
| Janelas do app | ⌃↓ | |

No touchpad, deslize para o lado com três dedos. Quatro dedos para cima abrem a visão geral se os gestos de
quatro dedos estiverem ativados em [Touchpad e tela sensível ao toque](help:trackpad).

Escolher uma janela leva à área de trabalho dela: o Dock, o seletor de apps e as notificações pulam para lá.

## Mover uma janela

Menu Janela → **Mover para área de trabalho**. Apps com barra própria têm isso no menu do clique direito na barra.

## Ctrl e as setas

Em muitos apps ⌃← e ⌃→ movem por palavra. Se preferir assim, desative-as em
[Ajustes → Teclado](settings:keyboard); ❖⌃← e ❖⌃→ continuam trocando de área de trabalho.

## Bom saber

- Uma janela de outra área de trabalho nunca recebe o que você digita.
- Os apps continuam rodando nas outras áreas de trabalho, e um vídeo em picture-in-picture acompanha você em todas.
- Suas janelas voltam às suas áreas de trabalho no próximo login.

# Welcome to Axia DE

Axia DE is a free GNU/Linux distribution based on Debian, with its own desktop environment built
from scratch: a display server and Wayland compositor written in C, and a React interface running
on its own engine. Linux apps (GTK, Qt, browsers) run alongside the native ones. It is designed to
run well on modest hardware.

## First steps

- **Open apps:** the Dock (at the bottom) or Apps (**F4**, or tap the ❖ key on its own).
- **Find anything:** **❖Space** opens Search. See [Search](help:spotlight).
- **Change the look:** [Settings → Appearance](settings:appearance) and [Wallpaper](settings:wallpaper).
- **Get online:** [Settings → Network](settings:network).
- **Lock the screen:** **❖L**.

The ❖ key is the Super key (the logo key between Ctrl and Alt on most keyboards): almost every app
shortcut uses it.

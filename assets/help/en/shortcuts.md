# Keyboard shortcuts

❖ is the Super key, ⌃ Ctrl, ⌥ Alt and ⇧ Shift. [Settings → Keyboard](settings:keyboard) lists the
shortcuts of the theme you are using.

## In every theme

| Shortcut | What it does |
|---|---|
| ❖Space · ⌃Space | Search: find apps, files, settings and help |
| ❖⌥Space · ⌃⌥Space | Next keyboard layout or input method |
| ❖V · ❖⇧V | Clipboard: latest items · full history |
| ❖. | Emoji and symbols |
| ❖⇧3 · Print Screen | Screenshot of the whole screen |
| ❖⇧4 | Screenshot of an area (Space: of a window) |
| ❖⇧5 | Screenshots panel and screen recording |
| ❖L · ❖⌃Q | Lock the screen |
| ❖Q | Quit the app |
| Media keys | Play, pause, next and previous in Player |

## Switching apps

Hold the modifier and press Tab: a strip of app icons shows the selected app's name, the most
recently used first. Tab moves, ⇧Tab goes back, Esc cancels, and releasing the modifier switches. A
quick press goes back to the previous app.

## Lord Flow

| Shortcut | What it does |
|---|---|
| ❖ alone · F4 | Apps (the app launcher) |
| ❖Tab · ❖⇧Tab | Switch apps |
| ⌃↑ · ⌃↓ | Overview · windows of the app ([Desktops](help:desktops)) |
| ⌃← ⌃→ | Previous or next desktop |
| ❖\` · ❖⇧\` | Next or previous window of the app |
| ❖M | Minimize the window |
| ❖H · ❖⌥H | Hide the app · hide the other apps |
| ❖⌥Esc | Force Quit |
| ❖F11 | Show the desktop, and back |
| ❖⌥D | Hide or show the Dock automatically |
| ❖, | The app's settings |

In a Linux app, ❖C, V, X, A, Z, F, T, W, N, L, R, P and S arrive as Ctrl (as Ctrl+Shift in a terminal
emulator, where Ctrl+C is the interrupt), to that app only. So ❖V pastes and ❖L is its own Ctrl+L
there: with a Linux app in front the screen locks with ❖⌃Q, and the clipboard opens with ❖⇧V. In a
LordOS app inside the session ❖V pastes too; ❖⇧V is the clipboard.

## In apps

⌃Tab and plain ⌃Q always stay with the app: in Terminal, ⌃Q is the terminal's own.

| Shortcut | What it does |
|---|---|
| ❖N · ❖T · ❖W | New window · new tab · close (Lord Classic: ⌃N, ⌃T, ⌃W) |
| ❖F · ❖G | Find · next result |
| ❖C · ❖X | Copy · cut |
| ❖Z · ❖⇧Z | Undo · redo |
| ❖S · ❖P | Save · print |

Each app explains its own in its article: [Files](help:files), [Terminal](help:terminal),
[Text Editor](help:editor) and [Notes](help:notes).

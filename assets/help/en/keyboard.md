# Keyboard and input methods

## Layouts

In [Settings → Keyboard](settings:keyboard) you add the layouts you use (any XKB layout: US,
Latin American, Spanish, Portuguese, Arabic, Hebrew…). The active one shows in the menu bar; a click
there or **❖⌥Space** switches to the next.

## Input methods

To type languages with many characters, Axia DE has its own input methods:

- **Korean** (한): letters are composed into syllables as you type.
- **Japanese** (あ, SKK): type in romaji; Space converts to kanji and Enter confirms.
- **Chinese** (拼, pinyin): type pinyin and pick the character with the number keys.

Add them like a layout, in Settings → Keyboard. They work in every Axia DE app and in Terminal.

## Emoji and symbols

**❖.** opens the emoji picker below the cursor. See [Emoji & Symbols](help:characters).

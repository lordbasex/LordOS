# Updates

Axia DE is built on Debian and updates itself with its own package engine, which verifies Debian's
signatures before using anything.

- [Settings → Updates](settings:updates) checks for updates and shows how many there are.
- **Show in Store** lists them and installs them all together, showing the plan first (what
  changes and how much is downloaded).

Installing updates requires an administrator. You can keep using the computer while they install.

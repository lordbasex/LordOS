# About LordOS

Shows the LordOS version, the computer (processor, memory, graphics card), the Linux kernel and how
the display server is drawing (GPU or CPU).

It's the first thing worth looking at —or copying— when reporting a problem. For more detail on
what the computer is doing, open [Monitor](help:monitor), and to see what happened, [Logs](help:logs).

To tell the project how LordOS runs on this computer, open System Information → Report → **Share on
GitHub**: it saves a report with no serial numbers or addresses and opens the form. What others have
reported, machine by machine, is in `docs/HARDWARE-REPORT.md` in LordOS's repository on GitHub.
